# Technical Appendix

## Dataset Overview
- Source files:
  - data/data_set_ALL_AML_train.csv
  - data/data_set_ALL_AML_independent.csv
  - data/actual.csv
- Samples:
  - Training: 38 (ALL: 27, AML: 11)
  - Independent test: 34 (ALL: 20, AML: 14)
- Features:
  - 7,129 gene expression measurements per sample
- Labels:
  - Diagnosis labels (ALL, AML)

## Data Schema
- data_set_ALL_AML_train.csv and data_set_ALL_AML_independent.csv
  - Gene Description (string)
  - Gene Accession Number (string)
  - Expression columns: numeric sample identifiers (e.g., 1..38, 39..72)
  - Call columns: presence/absence calls (ignored in analysis)
- actual.csv
  - patient (int)
  - cancer (string: ALL or AML)

## Preprocessing
- Only numeric sample columns are used as expression values.
- Gene information columns retained for labeling and metadata.
- Expression matrix is transposed to sample x gene layout.

## Statistical Methods
- Differential expression:
  - Welch's t-test (unequal variance) per gene
  - Multiple-testing control using Benjamini-Hochberg FDR
- Effect size:
  - Cohen's d computed per gene
- Dimensionality reduction:
  - PCA on standardized expression values
- Correlation analysis:
  - Pairwise Pearson correlation between samples
  - Pair categories: ALL-ALL, AML-AML, ALL-AML

## Visualization Rules Applied
- No pie charts
- All charts use bar/line/scatter/box/point plots
- Numeric values displayed on bars or points where applicable
- High-resolution output
- Clear titles, axes, and legends

- All charts are generated by scripts/generate_charts.py
- The script is executable end-to-end from project root

## Limitations
- No demographic or clinical covariates (age, sex, treatment, outcomes).
- No longitudinal data; temporal analysis not possible.
- Results are limited to molecular expression signals and diagnosis labels.
- Clinical conclusions should be validated with external cohorts.
